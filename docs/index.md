# Indice della Documentazione - Tema Zero

> **Nota 2026-07-24**: indice storico senza frontmatter, ridondante rispetto a
> [00-index.md](./00-index.md) (canonico, aggiornato 2026-03-28). Usare `00-index.md` come riferimento
> primario; questo file non è stato consolidato per evitare di perdere la prosa introduttiva italiana.

## Panoramica
Questo documento serve come indice centrale per il tema Zero, fornendo una guida per la personalizzazione e l'utilizzo del tema all'interno dell'applicazione Laravel. Il tema Zero è un tema basato su TailwindCSS con supporto per Vite e componenti Blade moderni.

## Duplicati noti (non cancellati, solo documentati)

Il tema ha subito piu' ondate di rinomina/consolidamento che non sono mai state
completate fino in fondo. La forma canonica dei nomi file e' **kebab-case**, per
regola esplicita gia' presente in [naming-conventions.md](./naming-conventions.md)
("Doc Files - Format: `kebab-case.md`") e
[model-docs-governance.md](./model-docs-governance.md) ("Prefer canonical
`kebab-case` docs filenames"). In pratica pero' in `docs/` root convivono ancora
varianti `UPPERCASE`/`snake_case` dello stesso contenuto (o di un fork quasi
identico), quasi tutte introdotte in blocco il 2026-09-09 (commit radice
`0d6cf4c` di questo repo) quando la storia git del tema e' stata ricreata da un
working tree che le conteneva gia'. Dettaglio investigativo completo nella story.
