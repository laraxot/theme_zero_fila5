Procedura da seguire:
1. Vai in laravel/Themes/Zero.
2. Esegui git remote -v e usa solo gli org emersi dai remote reali. Non dedurre l'org da nomi progetto, report o memoria.
3. Esegui git fetch --all --prune.
4. Confronta HEAD con ogni remote dev:
   - git rev-list --left-right --count HEAD...laraxot/dev;
   - git rev-list --left-right --count HEAD...provtv/dev.
5. Interpreta i due numeri:
   - primo numero > 0 e secondo numero = 0: HEAD e' avanti, puoi fare push fast-forward;
   - secondo numero > 0: il remote ha commit non presenti localmente, fermati e documenta la divergenza;
   - 0 0: gia' sincronizzato.
6. Non usare mai force push, reset, restore, checkout, switch o revert.
7. Fai push separati e verificabili:
   - git push laraxot dev;
   - git push provtv dev.
8. Dopo ogni push, ripeti i confronti rev-list. La chiusura corretta e':
   - HEAD...laraxot/dev = 0 0;
   - HEAD...provtv/dev = 0 0;
   - git status --short --branch senza file modificati.
